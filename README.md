# Aplicativos Gui.BYD V3.3

## Novidades
- Atualizações: primeiro Aplicativos Gui.BYD, depois YouTube.
- Barra de progresso para download do próprio app e do YouTube.
- Banner remoto no topo, adaptado a retrato/paisagem.
- Banner administrável pelo Gui.BYD Admin Web.
- Detecção de atualização do app pelo `versionName` (ex.: 3.2 -> 3.3), sem depender do version code publicado no servidor.
- Aviso de atualização reaparece a cada nova abertura/retorno do app enquanto a versão instalada estiver atrás da publicada.

## Versão Android
- versionName: 3.3
- versionCode interno: 6

O versionCode interno continua sendo incrementado no APK para permitir atualização Android, mas não precisa mais ser digitado no Admin.
